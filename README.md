# task26092812

`fatfs` — 只读 FAT12/16/32 取证解析库（Go）。输入为单卷 raw dd 镜像
（第 0 字节即引导扇区），行为以微软 FAT 规范为准。

## API

- `Open(path)` — 解析 BPB，给出 FAT 类型（仅由数据区簇数决定）、簇大小、簇数
- `(*Volume).Walk(fn)` — 对每个目录条目（含已删除）回调：完整路径、长名、
  短名、属性、大小、首簇、修改/创建/访问时间、删除标记、恢复状态、异常标注
- `(*Volume).ReadFile(entry, w)` — 输出条目内容；已删除文件按首簇起连续
  存放的假设取回

## 关键性质

- FAT 类型只由数据区簇数决定，忽略 `BS_FilSysType` 与 BPB 字段非零情况
- LFN 组合：活条目要求序号连续 + 校验和匹配；已删除条目要求校验和一致
  （序号字节已被 0xE5 覆盖）；凑不成组的 LFN 丢弃
- 已删除短名首字符通过 LFN 校验和还原，无法还原合法字符则 LFN 组无效，
  无 LFN 时用 `_`；无 LFN 条目按 NT 大小写标志位还原
- 首字节 0x05 表示真实首字符 0xE5；0x00 终止目录
- 恢复状态三选一：完整 / 部分覆盖 / 不可恢复
- 已删除目录仅当首簇空闲且前两项为指向自身与父目录的 `.` `..` 时进入，
  只解析首簇，其中条目一律视为已删除
- 时间戳按卷上本地时间输出，创建时间 10ms 精度；非法字段一律为空，
  不做进位规范化
- 不可信输入安全：簇链成环、目录指回祖先、簇号越界、镜像截断都只产生
  异常标注；不 panic、不挂起、不按损坏字段分配内存（链长 / 目录字节数 /
  递归深度均有上限）

## 测试

```sh
go test ./...                              # 单元测试（镜像全部按字节构造）
go test -run '^$' -fuzz FuzzOpenWalk -fuzztime 60s .
```

覆盖：FAT12/16/32（含错误的 `BS_FilSysType`）、三段 LFN 的已删除文件
（长名以 `.` 开头、短名还原、逐字节恢复、部分覆盖）、子目录指回祖先、
稀疏文件构造的 100 GiB FAT32（Open+Walk 微秒级）、Go 原生 fuzz。
